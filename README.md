# Bernhard — Webdesigner Website

Portfolio-Website für Bernhard, gebaut mit Next.js (App Router), TypeScript, Tailwind CSS 4 und Framer Motion.

## Struktur

- `src/app/` — Layout, globale Styles und die Startseite
- `src/components/` — Sections: Navbar, Hero, Marquee, About, Services, Work, Testimonials, Contact, Footer

Alle Texte, Projekte und Kontaktdaten sind aktuell Platzhalterinhalte und sollten vor dem Launch durch echte Inhalte ersetzt werden.

## Entwicklung

```bash
npm install
npm run dev
```

Öffne [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```
